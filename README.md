# Drill13

Python과 `pico2d`, `transitions`가 설치된 환경에서 프로젝트 폴더를 열고 실행합니다.

```sh
python main.py
```

| 화면 | 키 | 동작 |
| --- | --- | --- |
| 타이틀 | Space | 게임 시작 |
| 플레이 | ← / → | 이동 |
| 플레이 / 아이템 선택 | Space | 선택한 공 발사, 수면 중에는 깨우기 |
| 플레이 | P | 일시정지 |
| 일시정지 | P | 플레이 재개 |
| 플레이 | I | 아이템 선택창 열기 |
| 아이템 선택 | 0 | 볼 없음 선택 후 플레이 복귀 |
| 아이템 선택 | 1 | 작은 볼 선택 후 플레이 복귀 |
| 아이템 선택 | 2 | 큰 볼 선택 후 플레이 복귀 |
| 아이템 선택 | I | 선택을 유지하고 플레이 복귀 |
| 타이틀 / 플레이 / 아이템 선택 / 일시정지 | Esc | 게임 종료 |

아이템 선택창은 `item_select.png`를 사용합니다. 창이 열려 있어도 이동, 공의 움직임, 애니메이션, 수면 타이머가 계속 진행됩니다. 일시정지 화면에서는 게임 업데이트가 멈춥니다.

기본 선택은 작은 볼입니다. 작은 볼은 `ball21x21.png`, 큰 볼은 `ball41x41.png`를 원본 크기로 표시합니다. 선택은 이후 발사하는 공에 적용되며, 이미 발사한 공은 그대로 유지됩니다. 볼 없음 상태에서는 Space를 눌러도 새 공을 발사하지 않습니다.

회귀 테스트는 게임 창 없이 실행할 수 있습니다.

```sh
python -m unittest discover -v
```
